# 📝 Notes 사용 가이드

GitHub 계정 하나로 여러 기기에서 동기화되는 마크다운 노트 앱입니다.
모든 데이터는 여러분의 GitHub 계정(Gist·저장소)에 저장되며, 별도의 서버는 없습니다.

---

## 1. 처음 시작하기 (등록)

1. **GitHub 토큰 발급**
   로그인 화면의 "토큰 발급 (gist + repo 권한)" 링크를 눌러 GitHub에서 Personal Access Token을 발급받습니다.
   (`gist`, `repo` 권한 체크 필수)
2. **등록**
   - 발급받은 토큰(`ghp_...`)을 입력
   - 코드는 직접 입력하거나 🎲 버튼으로 자동 생성 가능 (선택 사항)
   - 로그인용 비밀번호를 설정 (4자 이상)
3. 등록이 끝나면 `GitHub아이디/코드` 형태의 **로그인 ID**가 발급됩니다. 이 ID와 비밀번호를 안전한 곳에 보관하세요. 다른 기기에서도 이 ID + 비밀번호로 로그인하면 같은 노트를 이어서 사용할 수 있습니다.

> 🔒 토큰은 AES-256으로 암호화되어 저장되며, 원문 토큰은 브라우저 밖으로 나가지 않습니다.

---

## 2. 노트 작성

- 사이드바의 **"+ 새 노트"** 버튼으로 새 노트를 만듭니다.
- 상단 제목 입력란에 제목을, 아래 편집창에 마크다운으로 본문을 작성합니다.
- 상단 탭에서 **편집 / 미리보기**를 전환할 수 있습니다.
- 편집창 위 툴바 버튼(굵게, 기울임, 제목, 목록, 인용, 코드, 표, 링크, 첨부 등)을 눌러 서식을 빠르게 삽입할 수 있습니다. 각 버튼에 마우스를 올리면 단축키가 표시됩니다. (전체 단축키는 상단의 **⌨ 버튼** 참고)

### 이미지 · 파일

- 툴바의 📎(첨부) 버튼이나 `Ctrl+Shift+P`로 파일을 선택해 업로드할 수 있습니다.
- 스크린샷이나 복사한 이미지를 편집창에 **`Ctrl+V`로 바로 붙여넣기**하면 자동으로 업로드되어 삽입됩니다.
- 미리보기 화면에서 삽입된 **이미지를 클릭**하면 크기 조절 팝업이 열립니다. 25% / 50% / 75% / 100% 비율이나 원하는 px 값을 직접 입력해 크기를 바꿀 수 있고, "원본 크기로" 버튼으로 되돌릴 수 있습니다.
- 상단의 📎(파일 관리) 버튼을 누르면 그동안 업로드한 파일 목록을 확인·삽입·다운로드·삭제할 수 있습니다.
- 업로드한 파일은 [설정 → 파일 저장소 설정]에서 지정한 GitHub 저장소에 저장됩니다. **처음 파일을 첨부하기 전에 이 저장소를 먼저 설정**해야 합니다.

---

## 3. 노트 정리하기

- **폴더**: 상단의 📁+ 버튼으로 새 폴더를 만들고, 사이드바에서 폴더를 드래그해 순서/위치를 옮길 수 있습니다. 노트를 폴더 목록으로 드래그하면 해당 폴더로 이동합니다.
- **태그**: 노트 편집 화면 하단에서 태그를 추가/삭제할 수 있습니다. 사이드바의 "태그" 섹션에서 태그를 눌러 필터링할 수 있습니다.
- **즐겨찾기**: 노트 목록에서 별표(★)를 클릭하면 즐겨찾기에 추가/해제됩니다. 사이드바의 "⭐ 즐겨찾기"에서 모아볼 수 있습니다.
- **정렬**: 사이드바 노트 목록 위 드롭다운에서 최신순 / 오래된순 / 제목순 / 수정순으로 정렬할 수 있습니다.
- **검색**: 사이드바 상단 검색창에 제목/본문 키워드를 입력하면 즉시 필터링됩니다.
- **휴지통**: 🗑 버튼으로 삭제된 노트를 확인하거나 복구할 수 있습니다. 노트를 선택한 상태에서 `Delete` 키를 누르면 휴지통으로 이동합니다.

---

## 4. 저장 & 동기화

- 우측 상단의 **💾 저장** 버튼(또는 `Ctrl+S`)을 누르면 현재 노트 내용이 GitHub Gist에 저장·동기화됩니다.
- 모바일에서도 같은 버튼으로 저장할 수 있습니다.
- 사이드바의 **"☁ Gist 저장 · 동기화"** 버튼으로도 동일하게 저장할 수 있습니다.

---

## 5. 노트 공유

- 노트를 열고 상단의 🔗(노트 링크 공유) 버튼을 누르면 해당 노트를 볼 수 있는 공유 링크가 생성됩니다.
- 공유 링크를 받은 사람은 로그인 없이 해당 노트를 읽기 전용으로 볼 수 있습니다.
- 저장소가 비공개(private)인 경우, 노트 안의 이미지는 공유받은 사람에게 보이지 않을 수 있습니다.

---

## 6. 백업 · 이동

- 사이드바 하단의 내보내기/가져오기 기능으로 노트를 백업하거나 다른 계정으로 옮길 수 있습니다.
  - **⬇JSON**: 전체 노트와 폴더 구조를 JSON 파일로 저장
  - **⬇MD**: 현재 선택한 노트를 마크다운(.md) 파일로 저장
  - **⬆불러오기**: JSON 백업 파일을 불러와 노트를 복원

---

## 7. 화면 설정

- 상단의 색상 원(●) 4가지로 테마(베이지/화이트/그린/다크)를 바꿀 수 있습니다.
- ⚙(설정) 버튼에서 에디터 글꼴, 글자 크기, 줄 간격, 문단 간격을 조절할 수 있습니다.
- ☰ 버튼으로 사이드바를 접거나 펼 수 있고, 사이드바 경계를 드래그해 폭을 조절할 수 있습니다.

---

## 8. 단축키

상단의 **⌨ 버튼**을 누르면 전체 단축키 목록을 언제든 확인할 수 있습니다. 자주 쓰는 것만 정리하면:

| 동작 | 단축키 |
|---|---|
| 저장 | `Ctrl+S` |
| 편집 모드 | `Ctrl+E` |
| 미리보기 모드 | `Ctrl+Alt+V` |
| 굵게 / 기울임 | `Ctrl+B` / `Ctrl+I` |
| 텍스트·이미지 붙여넣기 | `Ctrl+V` |
| 파일 첨부 | `Ctrl+Shift+P` |
| 노트 삭제(휴지통 이동) | `Delete` |

---

## 문의 / 문제 발생 시

- 이미지가 보이지 않는다면 [설정 → 파일 저장소 설정]에 저장소가 올바르게 지정되어 있는지 확인해 주세요.
- 로그인 ID나 비밀번호를 잃어버리면 계정을 복구할 방법이 없으니, 등록 시 반드시 별도로 저장해 두세요.
