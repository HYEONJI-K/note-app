# 📝 Note App - 마크다운 메모장

> 🔐 AES-256 암호화 기반의 안전한 개인 메모장  
> 폴더 정리 + 태그 필터링 + 마크다운 지원

![License](https://img.shields.io/badge/license-MIT-green)

---

## ✨ 주요 기능

### 🔐 보안
- **AES-256-GCM 암호화** - 모든 노트가 암호화되어 저장
- ID + 비밀번호 기반 인증
- 로컬 저장소(localStorage)에만 저장

### 📝 마크다운 에디터
- **풍부한 마크다운 지원** - 제목, 코드, 표, 인용구 등
- **실시간 미리보기** - 편집/미리보기 탭
- **단축키 지원** - Ctrl+B(굵게), Ctrl+I(기울임) 등
- HTML 붙여넣기 자동 변환

### 🗂️ 폴더 관리
- **계층적 폴더 구조** - 무제한 하위 폴더
- **폴더 접기/펼치기** - ▼/▶ 화살표로 토글
- **드래그 앤 드롭** - 폴더/노트를 간편하게 이동
- 폴더 이름 변경, 이동, 삭제

### 🏷️ 태그 기능
- **다중 태그 지원** - 노트에 여러 태그 추가
- **태그 기반 필터링** - 태그로 노트 분류
- **태그 자동완성** - 기존 태그 추천
- **태그 섹션 접기/펼치기**

### 🔗 위키식 링크
- `[[노트명]]` 형식으로 노트 간 링크 생성
- **실시간 자동완성** - `[[` 입력하면 매칭되는 노트 표시
- 미리보기에서 클릭하면 해당 노트로 즉시 이동

### 🎯 정렬 & 검색
- **4가지 정렬** - 최신순 / 오래된순 / 제목순 / 수정순
- **전체 텍스트 검색** - 제목과 본문 동시 검색
- 폴더/태그별 필터링
- 즐겨찾기 기능

### 🎨 테마
- **6가지 테마** - Light, Light White, Light Green, Dark, Dark Blue, Dark Purple

### ⚙️ UI 커스터마이제이션
- **사이드바 리사이즈** - 폴더/태그/노트 섹션 크기 조절
- **글자 크기 조절** - 에디터/미리보기 글자 크기 변경
- **줄 간격 조절** - 읽기 편의성 향상
- **폰트 선택** - Courier New 지원
- 모든 설정이 자동 저장

### 💾 데이터 관리
- **자동 저장** - 타이핑하면서 자동 저장
- **휴지통** - 삭제된 노트 복구 가능
- **내보내기/불러오기** - JSON 파일로 백업/복원

### ⌨️ 편의 기능
- **풍부한 단축키** - Ctrl+S, Ctrl+B, Ctrl+E 등
- **제목 엔터** - 자동으로 본문으로 이동
- **노트 선택 시 스크롤** - 맨 위로 자동 이동
- **다중 선택** - Ctrl+Click으로 여러 노트 선택
- **드래그로 이동** - 노트를 폴더에 드래그

## 🚀 빠른 시작

### 사용 방법
1. `index.html`을 브라우저에서 열기
2. ID와 비밀번호 입력 (첫 로그인 시 자동 생성)
3. 메모 작성 시작

## 📚 사용 가이드

### 기본 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+S` | 저장 |
| `Ctrl+B` | **굵게** |
| `Ctrl+I` | *기울임* |
| `Ctrl+`` | `코드` |
| `Ctrl+Shift+1` | # 제목1 |
| `Ctrl+Shift+2` | ## 제목2 |
| `Ctrl+Shift+3` | ### 제목3 |
| `Ctrl+Shift+L` | 목록 |
| `Ctrl+Shift+K` | 체크박스 |
| `Ctrl+Shift+Q` | 인용 |
| `Ctrl+Alt+C` | 코드블록 |
| `Ctrl+Shift+T` | 표 |
| `Ctrl+Shift+U` | 링크 |
| `Ctrl+Shift+P` | 파일 첨부 |
| `Ctrl+E` | 편집 모드 |
| `Ctrl+V` | 미리보기 모드 |
| `Delete` | 노트 삭제 |

### 마크다운 문법

```markdown
# 제목 1
## 제목 2

**굵은텍스트**
*기울임텍스트*
~~취소선~~

- 목록
- 항목

- [ ] 미완료
- [x] 완료

> 인용구

| 표 | 헤더 |
|----|------|
| 셀1 | 셀2 |

[링크](https://example.com)
[[위키링크]]
```

### 폴더 & 태그
- 폴더로 주제별 정리
- 태그로 상태 분류 (긴급/완료/아이디어)
- 폴더와 노트는 드래그로 이동
- 폴더 앞 화살표로 펼침/접음

## 🔒 보안

### 암호화
- AES-256-GCM으로 모든 노트 암호화
- 로컬에만 저장 (서버 없음)
- 비밀번호는 절대 전송되지 않음

### 백업
1. 설정 → 내보내기 → JSON 다운로드
2. 설정 → 불러오기 → JSON 선택
