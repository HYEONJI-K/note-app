# 📝 Note App - 마크다운 메모장

> 🔐 AES-256 암호화 기반의 안전한 개인 메모장  
> 폴더 정리 + 태그 필터링 + 마크다운 지원

---

## 주요 기능

### 🔐 보안
- **AES-256-GCM 암호화** - 모든 노트가 암호화되어 저장
- ID + 비밀번호 기반 인증
- 로컬 저장소(localStorage)에만 저장

### 📝 마크다운 에디터
- 마크다운 지원 (제목, 코드, 표, 인용 등)
- 실시간 미리보기 (편집/미리보기 탭)
- 단축키 지원

### 🗂️ 폴더 관리
- 계층적 폴더 구조
- 폴더 접기/펼치기 (▼/▶)
- 드래그 앤 드롭으로 이동
- 폴더 이름 변경, 삭제

### 🏷️ 태그 기능
- 다중 태그 지원
- 태그 기반 필터링
- 태그 자동완성

### 🔗 위키식 링크
- `[[노트명]]` 형식으로 노트 간 링크
- 실시간 자동완성
- 미리보기에서 클릭으로 이동

### 🎯 정렬 & 검색
- 4가지 정렬: 최신순 / 오래된순 / 제목순 / 수정순
- 전체 텍스트 검색
- 폴더/태그별 필터링

### 🎨 테마
- 4가지 테마: Light, Light White, Light Green, Dark

### ⚙️ 설정
- 글자 크기 조절
- 줄 간격 조절
- 폰트 선택
- 사이드바 리사이즈

### 💾 데이터 관리
- 자동 저장
- 휴지통 (복구 가능)
- 내보내기/불러오기 (JSON)

---

## 🚀 사용 방법

1. `index.html`을 브라우저에서 열기
2. ID와 비밀번호 입력
3. 메모 작성

## ⌨️ 주요 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+S` | 저장 |
| `Ctrl+B` | **굵게** |
| `Ctrl+I` | *기울임* |
| `Ctrl+`` | `코드` |
| `Ctrl+Shift+1` | # 제목1 |
| `Ctrl+Shift+2` | ## 제목2 |
| `Ctrl+Shift+3` | ### 제목3 |
| `Ctrl+Shift+L` | 목록 |
| `Ctrl+Shift+K` | 체크박스 |
| `Ctrl+Shift+Q` | 인용 |
| `Ctrl+Alt+C` | 코드블록 |
| `Ctrl+Shift+T` | 표 |
| `Ctrl+Shift+U` | 링크 |
| `Ctrl+Shift+P` | 파일 첨부 |
| `Ctrl+E` | 편집 모드 |
| `Ctrl+V` | 미리보기 모드 |
| `Delete` | 노트 삭제 |

### 열(컬럼) 선택 모드 - Alt+드래그

에디터에서 `Alt` 키를 누른 채 드래그하면 여러 줄의 같은 컬럼 위치를 한 번에 선택할 수 있습니다.

- 선택 후 문자를 입력하면 모든 줄의 동일 위치에 동시 삽입됨
- `Backspace`/`Delete`로 선택 범위 동시 삭제
- `Escape` 또는 다른 곳 클릭 시 해제
- 고정폭 폰트(Courier New) 기준으로 동작
